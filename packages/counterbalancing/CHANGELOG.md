# @lightmill/counterbalancing

## 1.0.0

### Major Changes

- [#398](https://github.com/QuentinRoy/lightmill-js/pull/398) [`550328a`](https://github.com/QuentinRoy/lightmill-js/commit/550328a1eb123f6ab556a5b7c7f0ba22510df8ba) - Add `@lightmill/counterbalancing`, which generates condition orders to counterbalance runs: `latinSquare`, `permutations`, and `randomOrders`. It replaces `@quentinroy/latin-square`: use `latinSquare(conditions, { balanced: true })` for `latinSquare(conditions, true)`, and pass `Array.from({ length: n }, (_, i) => i)` as conditions for `latinSquare(n)`.
