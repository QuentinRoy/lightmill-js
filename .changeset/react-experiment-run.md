'@lightmill/react-experiment': minor

Add `Run`, a component that runs one experiment run for you. Pass it a `@lightmill/log-client` client, the experiment and run names, the log types it can resume after, a timeline builder, and your task components in `elements`. `Run` starts the run, plays the timeline, sends the logs from `useLogger` to the server, and completes the run once every log is stored. It asks the browser to confirm before the page unloads until the run ends. When the participant has an ongoing run with the same experiment and run names, `Run` asks before resuming it and builds the timeline from the last log whose type is in `resumableLogTypes`, so stateful timelines resume correctly. `elements.resume` replaces the default prompt and reads the run and its last log with `useResumeRun()`. While logs cannot be delivered, `Run` shows `elements.paused`, so the participant never works on progress that is not saved. Its default has a retry button and a link to download the logs that were not saved. `useLogDelivery()` returns `{ error, inFlightLogs, retry }` to write your own paused screen; `retry` never rejects. Its loading, resume, paused and completed screens have defaults, which `elements.loading`, `elements.resume`, `elements.paused` and `elements.completed` replace. React Strict Mode and remounts never start a run twice. `@lightmill/react-experiment` does not import `@lightmill/log-client` at runtime.
