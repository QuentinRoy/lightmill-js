'@lightmill/react-experiment': minor

Add `Run`, a component that runs one experiment run for you. Pass it a `@lightmill/log-client` client, the experiment and run names, the log types it can resume after, a timeline builder, and your task components in `elements`. `Run` starts the run, plays the timeline, sends the logs from `useLogger` to the server, and completes the run once every log is stored. It asks the browser to confirm before the page unloads until the run ends. When the participant has an ongoing run with the same experiment and run names, `Run` asks before resuming it and builds the timeline from the last log whose type is in `resumableLogTypes`, so stateful timelines resume correctly. `elements.resume` replaces the default prompt and reads the run and its last log with `useResumeRun()`. While logs cannot be delivered, `Run` shows `elements.paused`, so the participant never works on progress that is not saved. Its default has a retry button and a link to download the logs that were not saved. `useLogDelivery()` returns `{ error, inFlightLogs, retry }` to write your own paused screen; `retry` never rejects. When the run cannot start or crashes (a task bug, a throwing builder, a refused completion), `Run` shows `elements.error` at once. It reads the thrown value unchanged with `useRunError()`, and renders outside `Run`'s own error boundary, so a slot that rethrows reaches your app's boundary. The default tells the participant to contact the experimenter, explains `RUN_EXISTS` and `ONGOING_RUNS`, and has a collapsed block of details for the experimenter, the download link while logs are held and a retry button while delivery is paused. After a crash `Run` interrupts the run once every log is stored, so a reload lands on the resume prompt; an interrupt failure is logged and never replaces the error. `useLogDelivery()` also works in the error slot when the run never started. Its loading, resume, paused, error and completed screens have defaults, which `elements.loading`, `elements.resume`, `elements.paused`, `elements.error` and `elements.completed` replace. React Strict Mode and remounts never start a run twice. `@lightmill/react-experiment` does not import `@lightmill/log-client` at runtime.
